One word for my Wi-Fi: **haunted**. It drops out at the worst moments, like something in the walls is messing with it. Running `main.ts` writes the word to `/output/entry.txt`.

The entry is a single word — no setup, no dependencies, just Node.

## Run it

```sh
node main.ts
```
